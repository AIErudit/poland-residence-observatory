# Contributing evidence

Open an issue using the source/correction template before changing a published number. Include the original publisher, exact URL, document date, table/page/cell, population, unit, reference period and extraction method. A useful contribution can be an official answer to a public-information request, a documented definition change or a corrected denominator.

Do not attach case files, chat exports, passport details or personal correspondence. Redact personal information before any upload. A cached official document can be retained outside the repository and referenced by SHA-256.

Create a branch. Run acquisition in staging mode, review differences, normalize accepted observations, update the independent verification and build the site. A second reviewer must check new evidence and public claims. Numerical tests do not authenticate a document or settle a legal interpretation.

If the publisher revises a dataset, preserve the previous observation in version history and add a correction to `CHANGELOG.md`. Do not silently splice incompatible definitions into a time series. Please keep criticism factual and focus on documented institutional actions rather than attributing motives to individuals.
